---
name: Orval Zod generation
description: Compatibility constraints for generating Zod contracts in this workspace.
---

Keep the Zod Orval target schema-only rather than also emitting TypeScript models into the same package, express integer-valued fields as `number` with `multipleOf: 1`, and format generated output before the workspace typecheck.

**Why:** The installed Orval/Zod combination produced barrel-name collisions for path parameter types when the Zod target also emitted TypeScript schemas. Orval's own formatting also left trailing blank lines that fail the repository's whitespace check. Orval 8 emits `zod.int()` for OpenAPI `integer`, but this workspace's Zod 3 release does not provide that method.

**How to apply:** After OpenAPI changes, use the existing API-spec codegen command and preserve its generation → formatting → library typecheck sequence. Use `type: number` plus `multipleOf: 1` for integer constraints until the workspace upgrades Zod; client-side TypeScript models remain generated by the React Query target.
