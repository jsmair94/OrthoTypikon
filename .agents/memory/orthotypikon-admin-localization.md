---
name: Admin interface languages
description: Product scope for the OrthoTypikon admin language selector.
---

The Arabic, English, and Greek language controls in the admin switch the whole admin interface, not only the content being edited.

**Why:** The user explicitly clarified that the controls must change the full admin interface after reporting that the displayed language names were not switchable.

**How to apply:** When changing admin localization, preserve global interface translation and Arabic right-to-left direction; keep content-specific language fields independently selectable.
